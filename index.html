    MCRL import table
    
        
    These same parts as one CSV table to import into MCRL, prepared the way the Smart CSV
          Converter prepares an SPC list: no flashbacks, primary stories only, each issue once per part, no commas.
          Columns Volume, #, SPC ERO, SPC RO, published, SPC Event, GCD volume. SPC ERO restarts at 1 in
          every part and SPC RO runs through them all. Not offered for scenes, because those rules would undo
          the scene detail.
